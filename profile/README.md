# InkyBench

**The open-source engineering workbench for professional developers.**

InkyBench is being built to combine project intelligence, research, execution, verification, persistent engineering experience, adaptable models and agents, and flexible compute while keeping engineering authority with the human developer.

> InkyBench augments the engineer. It does not replace one.

## Status

InkyBench is in its project-foundation stage. No product functionality is implemented yet.

### Implemented

- Organization, repository, governance, and contribution foundations.

### Planned

- Project intelligence, research, execution, verification, engineering experience, adaptable models and agents, and flexible compute.

The feather writes. The bench builds.
